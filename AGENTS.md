# Global rules

## Writing
- Use ASD-STE100 Simplified Technical English in replies, plans, docs and commit messages.
- Write one topic per sentence. Use max 20 words in a sentence, or 25 in a procedure.
- Use active voice and simple verb tenses. Give each word one meaning. Do not add filler.
- Write procedures as numbered steps, one command per step.
- Be direct. If the user's data or plan is wrong, say so.
